# Knowledge lifecycle

1. Classify and clean the source.
2. Create a knowledge base or standalone document.
3. Upload text/file or import a permitted URL.
4. Wait for `ready`; handle `failed` explicitly.
5. Search with representative and adversarial questions.
6. Attach IDs to the agent draft and deploy.
7. Test spoken behavior.
8. Refresh, replace, or delete stale material and retest.

Never treat `pending` or `processing` as usable. Preserve a source owner and
review date for operational content.
