# Vapi mapping review

Review automatic candidates for prompts, first messages, voice, language, model,
supported function tools, transfer/end behavior, knowledge, voicemail, silence,
and maximum duration.

Plan manually for phone numbers, server URLs and callbacks, credentials,
squads/workflows, vendor-specific tools, and unsupported provider settings.

For every selected assistant, record source ID, import item ID, created
ThunderPhone agent ID, deployed revision, unresolved gaps, and side-by-side test
evidence. Sources: [import guide](https://thunderphone.com/docs/guides/import-agents.md),
[agent imports](https://thunderphone.com/docs/api-reference/agent-imports.md).
